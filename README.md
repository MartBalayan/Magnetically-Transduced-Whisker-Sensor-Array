# Magnetically Transduced Whisker Sensor Array

### Development of a Bio-Inspired Tactile Sensing System

A multidisciplinary engineering project focused on the development of a magnetically transduced whisker sensor array, integrating sensor hardware, custom PCB design, embedded firmware and simulation.

---

## Project Overview

Biological whiskers provide an effective mechanism for detecting and interpreting interactions with the surrounding environment. Inspired by this sensing capability, this project explores the development of an artificial whisker-based sensing system using magnetic transduction.

The project brings together electronics, embedded systems and simulation to investigate the implementation of a sensor array capable of translating mechanical interactions into measurable electronic signals.

Developed as part of a Master's thesis, the work encompasses multiple stages of engineering development, from hardware design and embedded software implementation to simulation and system integration.

## Key Engineering Areas

- **Sensor Development:** Magnetically transduced whisker sensing architecture.
- **PCB Design:** Electronic circuit and printed circuit board development.
- **Embedded Systems:** STM32-based firmware development and hardware interfacing.
- **Simulation:** MuJoCo-based simulation and modeling.
- **System Integration:** Integration of hardware, firmware and simulation components.

## Project Architecture

The project is organized into three main technical components:

### 1. Sensor Electronics and PCB Design

The electronic hardware provides the interface between the sensing elements and the embedded processing system.

This part of the project covers the PCB design and electronic implementation required for the sensor array.

**Documentation and design files:** [PCB Design](./PCB%20Design/)

### 2. Embedded Firmware — STM32

The embedded processing system is based on an STM32 microcontroller.

The firmware provides the software foundation for interfacing with the sensor electronics and processing acquired information.

**Source code:** [STM32 Core Files](./STM32%20Core%20Files/)

### 3. Simulation — MuJoCo

MuJoCo is used as the simulation environment for the project.

The simulation component provides a framework for modeling and investigating the system's behavior.

**Simulation files:** [MuJoCo Simulation](./Mujoco%20Simulation/)
